# 玄枢排盘

一个独立的 Flutter 术数排盘项目，工程代号仍为 `qimen`，目录位置在 `/Users/aoliao/Documents/qimens`。

## 当前版本

- 支持奇门遁甲排盘
- 支持紫微斗数基础命盘
- 支持七政四余排盘
  含地点、时区、命度、身度、宿度、圆盘总览、十一曜躔次与值日宿层

## 说明

当前版本是工程化第一版，先把三个主要入口和基础盘骨架接通，其中七政四余已经开始从西洋化展示回收为古法校准盘表达，当前主打命度、身度、宿度、值日宿与圆盘总览，方便你继续往下扩展。

如果后面要做得更完整，建议继续加：

- 节气判断
- 干支换算
- 自动定阴遁 / 阳遁
- 自动定局数
- 值符值使的传统算法
- 历史盘保存与导出

## 运行

```bash
cd /Users/aoliao/Documents/qimens
```
