# 玄枢排盘

一个独立的 Flutter 术数排盘项目，工程代号仍为 `qimen`，目录位置在 `/Users/aoliao/Documents/qimens`。

## 当前版本

- 支持奇门遁甲排盘
- 支持紫微斗数基础命盘
- 支持七政四余排盘
  含地点、时区、命宫、身宫、命度、身度、宫主、度主、身度主、宫度主论、宿度、二十八宿落度、宿度分金、圆盘总览、十一曜躔次与值日宿层

## 说明

当前版本是工程化第一版，先把三个主要入口和基础盘骨架接通，其中七政四余已经收口为古法校准盘表达，当前主打命宫、身宫、命度、身度、宫主、度主、身度主、宫度主论、宿度、值日宿与圆盘总览；外圈已按二十八宿落度绘制，并补上宿度分金、安命度法与主星层次，方便你继续往下扩展。

如果后面要做得更完整，建议继续加：

- 节气判断
- 干支换算
- 自动定阴遁 / 阳遁
- 自动定局数
- 值符值使的传统算法
- 历史盘保存与导出

cd /Users/aoliao/Documents/qimens
