# qimen

一个独立的 Flutter 奇门遁甲排盘项目，目录位置在 `/Users/aoliao/Documents/qimen`。

## 当前版本

- 支持手动选择 `阴遁 / 阳遁`
- 支持手动选择 `1-9局`
- 支持选择起局日期与时间
- 支持九宫盘面展示
- 展示值符、值使、值星、时辰等摘要信息

## 说明

当前版本是工程化第一版，先以“手动局数 + 手动阴阳遁”的方式起盘，方便你继续往下扩展。

如果后面要做得更完整，建议继续加：

- 节气判断
- 干支换算
- 自动定阴遁 / 阳遁
- 自动定局数
- 值符值使的传统算法
- 历史盘保存与导出

## 运行

```bash
cd /Users/aoliao/Documents/qimen
flutter pub get
flutter run
```
